Findings during the step
  - -Wno-cpp hid kernel/include/uapi/linux/types.h's "kernel headers
    from user space" #warning in the 7 binaries using msmipc.h. Fixed
    by giving them only a build-dir copy of the exported UAPI header
    linux/msm_ipc.h; device binaries byte-identical to the baseline.
  - wlan.ko differed on every build: a mktemp build path in 78
    __FILE__ strings and qcacld's Kbuild TIMESTAMP (date -u). Fixed
    path out/wifi-build plus TIMESTAMP from the pinned qcacld commit's
    committer date. Reproducible per checkout path (__FILE__ carries
    the absolute path).
  - test_chef_reboot.py failed whenever its suite ran as an async job
    of a non-interactive shell: such jobs start with SIGINT and SIGQUIT
    ignored and a non-interactive shell cannot trap a signal ignored on
    entry. Test resets them in the child; make test runs suites as make
    prerequisites. Product unaffected (chef-reboot then carries on to
    the bootloader; TERM still interrupts it).
  - chefui storage tests flaked because their fixture lives on the
    host's shared /tmp tmpfs; the product correctly reports an estimate
    when free space changes mid-scan. Bounded retries (100) only for
    that case, a deterministic test still covers the estimate path.
