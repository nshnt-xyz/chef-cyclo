5. Found while installing (not blockers)
W1: the Wi-Fi radio switch is not persisted across reboots. The settings switch sets NetworkManager's WirelessEnabled, which NetworkManager keeps in RAM
(/var/lib/NetworkManager); /data/v1/networkmanager holds only the connections. After every boot the radio is enabled and wlan0 connects to the known network.
Seen on both RAM boots of this install (the radio had been turned off on the previous boot) and again on the installed pair; the same code ran on 1bb8a700 (no NetworkManager change in the range), not observed there. Recorded in
docs/next-steps/connectivity-and-sensors.md.
Other: the chefui-demo binary is in the image diff because it links the same chefui fbscreen layer.
